# v0.1.1 - Kerkyra stabilization experiments

This update adds release builds and mounted-drive exports configured through a private settings file outside the repository. The exporter validates the archive and internal checksums, skips identical copies, and refuses conflicts. The v0.1.0 ZIP remains the initial freeze; the three working experiment scripts and seven example videos are unchanged.

Two examples of circumstance-specific, AI-assisted video coding, shared as a starting point for another vibe coder and their AI tool.

- The final sunrise, aircraft, and feedback-analysis Python scripts, preserved unchanged.
- A ready-to-paste AI prompt and agent instructions, implementation maps, hardcoded-setting references, and explicit reproduction recipes.
- Seven small source/before/after viewing previews included directly in the repository and ZIP.
- Historical case studies covering the island-to-sun handoff, one feedback iteration, the aircraft dip fix, the restored ending, and vertical composition.
- MIT license for code/docs and separate example-footage terms.

Start with `START_HERE.md`. This release intentionally keeps the assumptions of the original two recordings; it does not add arbitrary-footage support or an editing application. The compact examples are viewing proxies, not camera-original inputs for the unchanged settings.

An editor-friendly experience is a later project, recorded in `ROADMAP.md`.
