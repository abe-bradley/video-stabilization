# Future work

Version 0.1.0 is complete when another AI coder can understand the examples and adapt one to a particular recording. It preserves the code that produced the original results.

The author intends to return to this project for an editor-friendly experience. Possible later work, in a separate development phase:

1. Select a subject box and scene boundary visually; preview composition and crop before analysis.
2. Replace clip constants with a configuration format that the program actually loads.
3. Consolidate shared media/transform code while retaining the scene-specific trackers.
4. Make timing, source color, rotation, audio, and HDR handling explicit across supported inputs.
5. Provide editable tracks, manual corrections, useful confidence displays, and straightforward exports.
6. Test broader footage and operating systems before defining a support matrix.
7. Evaluate a desktop interface or integration with an editing workflow.

No dates or universal tracking guarantees are attached to that work. Small, well-documented adaptations remain useful in the meantime.
