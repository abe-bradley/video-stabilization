# Changelog

## 0.1.1 - 2026-11-08

- Added explicit external local settings for release and mounted-drive export destinations.
- Added a release exporter that validates archive and file checksums, skips identical copies, and refuses conflicting existing files.
- Changed portable builds to default to `dist/`; private settings or `--output` can select a different release folder.
- Documented the active-development/archive/export split and added focused export-helper checks.

The v0.1.0 ZIP is retained as a freeze. The three original stabilization/feedback scripts and included media are unchanged.

## 0.1.0 - 2026-11-08

First public-ready packaging of the August 2026 Kerkyra experiments.

- Preserved the final sunrise, aircraft, and feedback-analysis scripts byte for byte.
- Added an AI-coder starter prompt, agent instructions, adaptation guide, implementation maps, and explicit-path reproduction commands.
- Documented the original clip settings, feedback experiment, aircraft dip fix, full ending, and 30%-from-bottom composition.
- Included compact before/after proxies directly in the repository; originals and full-resolution masters are excluded.
- Added MIT licensing for code/docs, separate example-footage terms, provenance hashes, release checks, and a ZIP builder.

This packaging release does not change the stabilization algorithms or add arbitrary-footage support. The archived per-clip READMEs describe the historical working folders; current reproduction instructions are in `docs/REPRODUCING.md`.
